# MyPocketOS ロゴ資産

**状態: 正式ロゴは候補C2に確定(2026-09-21)。`final/` はC2のみ。既存画面へは未組み込み。**

## 目的

MyPocketOSの正式ロゴを、ベクター(SVG)で再構成して資産化する。
このディレクトリは「ロゴそのものの制作と整理」だけを扱う。壁紙・LightDM・Calamares・
GRUB・syslinux・README本体・仕様書・production codeへは、**まだ組み込んでいない**。

## 正式採用案: 候補C2

**3×3の円形ドット。左上が最大、右下が最小になるよう、半径が対角線1段ごとに一定量ずつ小さくなる。
青〜シアン系で、右下の1点だけにバイオレットのアクセントを置く。**

| 項目 | 値(記号のviewBox上のユニット。描画領域100、余白込みで108) |
|---|---|
| ドット中心 | 3×3、間隔34(中心は 16 / 50 / 84) |
| 半径 | 左上 15.0 → 13.5 → 12.0 → 10.5 → 右下 9.0(対角線1段ごとに1.5ずつ減少。r = 15.0 − 1.5×(行+列)) |
| ドット間の最小隙間 | 5.5(左上の大きい2つの間) |
| 小/大の半径比 | 0.60 |
| 色 | 斜め5段階で濃い青→シアン。右下の1点のみバイオレット(下記「色の考え方」) |

`final/mypocketos-logo-symbol.svg` の9個の円は、`candidates/mypocketos-logo-candidate-c2.svg` と同一である。

## 参考画像

`branding/reference/logo-concept-reference.png`(利用者が方向性を気に入った参考資料。生成AIによる
コンセプト画像)。**この画像のピクセルは一切使っていない。** 切り抜きでもトレースでもなく、
方向性だけを参考に、円と文字のアウトラインを座標から書き出したSVGである
(`tools/generate_logo_assets.py`)。

参考画像から引き継いだ要素:
- 3×3のドットグリッドという基本形、円形ドット
- 青の濃淡が中心で、右側にバイオレットを控えめに添える配色の方向
- ロゴタイプで「MyPocket」を濃紺、「OS」を明るい青にする2色の考え方

整理・再構成した点:
- ドット内のグラデーションをやめ、**単色の塗りつぶし**にした(小サイズで潰れにくく、単色化しやすい)
- 参考画像で2つあったバイオレット系のドットを、**1つ**に減らした(単色版では消える)
- 半径に段階的な差をつけ、「左上から右下へ小さくなる流れ」を形として持たせた
- 明背景用・暗背景用・単色用を、同じ幾何から機械的に書き出すようにした

## 採用した方向性(確定方針)

3×3ドットグリッド/「9」系統の雰囲気/シンプル・近未来・テック寄り/覚えやすい/
小さくても潰れにくい/意味づけをしない。
**不採用:** 葉っぱモチーフ、複雑な幾何学模様、過剰な装飾、細すぎる表現、キャラクター的要素、
壁紙へのロゴの焼き込み。

### C2を採用した理由

1. **意図して設計された段階に見える。** 段差が均一な一次関数(1.5ずつ)で、5段の直径が等間隔に並ぶ。
   初版Cは差が小さい(48pxでも段差0.8px)。
2. **16pxでも右下のドットが残る。** C2の最小ドットは16pxで約2.7px。C3は約2.0pxまで縮み、
   アクセントの色が淡く、ほとんど小さな点になる。
3. **左上が支配的にならない。** 左上と右下の面積差は、C2で約2.8倍、C3で約5.4倍。
4. 隙間は各案でほぼ同じ(5.4〜5.7)で、大きいドット同士が16pxでくっつくことはない。

| 32px | 8.9 | 5.3 | 0.89 |

## 色の考え方

青〜シアン系を基本とし、アクセントはバイオレット1点のみ。数値は**仮**で、最終決定は人間が行う。

| 用途 | 色 |
|---|---|
| ドット(明背景・斜め5段階) | `#0057D9` `#1573EA` `#2F8CFF` `#22A6FF` `#19C3FF` |
| ドット(暗背景・斜め5段階) | `#4A90FF` `#4FA0FF` `#55B2FF` `#3CC8FF` `#2FE0FF` |
| アクセント1点(右下) | 明背景 `#8A6CFF` / 暗背景 `#A58BFF` |
| ロゴタイプ(明背景) | 「MyPocket」`#0A1F5C`(濃紺)、「OS」`#0057D9` |
| ロゴタイプ(暗背景) | 「MyPocket」`#FFFFFF`、「OS」`#5BB2FF` |
| 単色 | `#0057D9`(明背景)/ `#FFFFFF`(暗背景) |

暗背景では、濃い青のドットが背景に沈むため、全体を明るい側へずらした別パレットを用意している。
単色版はアクセントが消えるが、ドットの位置・半径の違いだけで形は成立する。

## 小サイズ表示での意図

- 記号は、細い線を使わず、**塗りつぶしの円9個だけ**で構成している(細さで潰れない)。
- 隣のドットとの隙間は最小5.5ユニット(記号の幅の約5.5%)。16pxでは約0.8pxしかなく、
  細部はつぶれ気味になる。24px以上ではドットが分離して見える。
- 16pxでは、隣り合う段の差が1px未満(0.44px)のため、**段ごとの差は判別できない。**
  16pxで読み取れるのは「左上が大きく右下が小さい」という全体の流れだけで、段ごとの差が
  見え始めるのは24px以上(0.67px)である。
- 記号の周囲には、viewBox上で4ユニット(記号の幅の約4%)の余白を含めている。それ以上の
  「クリアスペース」規則は決めていない。
- ロゴタイプは、記号より文字が目立ちすぎないよう、文字の大文字高さを記号の高さの約半分にした。
  16px程度の小さい用途では、ロゴタイプではなく記号のみ(`symbol`)を使う想定である。
- 上記は確認シートの目視と幾何からの計算による。実際のディスプレイでは未確認。

## ロゴタイプの文字について(暫定・要確認)

**ロゴタイプの文字は暫定である。**「MyPocketOS」の文字は、**Liberation Sans Bold**のアウトラインを
SVGのパスにして埋め込んである(生成後のSVGはフォントに依存しない。文字はすべてパスで、
`<text>` 要素は使っていない)。このフォントはDebianの `fonts-liberation` パッケージに含まれ、
同パッケージの `copyright` ファイルでは **SIL Open Font License 1.1** と記載されている。

- OFLのもとでロゴ用途にアウトライン化した文字形状を使うことの可否は、**判断していない。**
  正式運用の前に、プロジェクト責任者が条件を確認すること。
- 文字形状は、参考画像の丸みのある幾何学的な書体とは異なる、一般的な無装飾のサンセリフである。
  独自のレタリングや別の書体への置き換えは今後の選択肢とする。置き換える場合も、記号(C2)は変えない。
- 記号のみの資産(`symbol`)は、この文字の扱いとは無関係である。

## 再生成の方法

```sh
python3 branding/logo/tools/generate_logo_assets.py --task all --final C2 \
    --out branding/logo --tmp <作業用ディレクトリ> \
    --wallpaper branding/wallpaper/mypocketos-wallpaper-standard-1920x1080.png
```

必要なもの: Python 3、PyGObject(`gi`)経由のRsvg 2.0、pycairo、Liberation Sans Bold。
`--wallpaper` は `preview/` の確認シートの背景用で、省略できる。
`--task c-refinement` は、候補C・C2・C3の比較シートだけを生成する(`final/` には触れない)。
